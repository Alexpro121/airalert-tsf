# AirAlert-TSF — технічний опис (виправлений)

Табличний класифікатор ризику тривоги на лагах погодинної сітки.
Ціль: `Y_t = max(A[t..t+2])`. Головна метрика — PR-AUC.

## Семантика часу

Момент прогнозу T = початок години t. Відомо `A[..t-1]`; ціль — поточна
година плюс дві наступні, справжній 3-годинний горизонт без пропущених годин.
Ембарго H на спліті та у фолдах (`TimeSeriesSplit(gap=H)`).
Доведено тестом `test_forecast_moment_variant_a`.

## Дані

Volunteer-дамп Vadimkin (з 2022-02-25, гілка main — не піновано).
Наївні часи = Europe/Kyiv (неоднозначна година → перше входження),
хвіст 6 год відрізано. `.meta.json` з source+sha256+URL+датою біля кожного
файлу; без sha файл вважається `unknown`. Синтетика — лише `--synthetic`,
в окремий файл. Аудит 2026-10-10: 115787 рядків, 0 нулів, 8.7% naive,
0% круглих годин.

## Ознаки (28)

Київський час: hour_sin/cos, dow_sin/cos, is_night. Лаги 1,2,3,6,24.
Вікна 6/12/24. `hours_since_last` (clip 168) + `has_history`. Сусіди t-1
без таргета, `country_ratio` (середнє сусідів). `has_threat_mention` /
`has_all_clear` (стеми з лівою межею слова; вимкнені без `--text-signals`).
Сітка перевіряється на строгу 1h-регулярність.

## Моделі та пороги

heuristic, persistence, always, climatology, dummy_logistic, LightGBM
(max_depth=6, lr=0.02, n=500, min_child_samples=40, subsample_freq=1; **без** scale_pos_weight).
Fallback HGB через єдину фабрику. Поріг: argmax F2 за умови
precision >= max(threshold_floor, ratio×prevalence_OOF) з Settings,
нічиї — вищий поріг.

## Калібрувальний зсув

Усі моделі систематично занижують на гарячому тесті (навчались на холодній
історії): mean-pred gap main +0.01, dummy −0.36, laghour −0.29; heuristic
завищує +0.40. A/B scale_pos_weight: PR-AUC 0.6450 vs 0.6432 (нульова різниця),
Brier 0.260 vs 0.304 — «покращення» лише від зсуву в бік гарячого тесту,
тому ваги лишаються вимкненими як стабільне правило.

## Обмеження (чесно)

- Таблична модель на лагах, не точковий процес; без заяв про «фізику» і Hawkes.
- Витік відсутній у межах реалізованих перевірок (20-точковий ручний аудит,
  behavioral тести ембарго); багаторазовий перегляд holdout визнається.
- Один 30-денний holdout; CI — парний блоковий bootstrap.
- SHAP: природний семпл (+balanced з суфіксом) + waterfall топ-епізоду.
  SHAP рахується на holdout; OOF-SHAP пропущено свідомо (вартість/користь).
  Fractional-фічі з сирих інтервалів (частка години в тривозі) не реалізовано:
  потребують субгодинної сітки — зафіксовано як відкрите обмеження.
- Ноутбуки виконані локально через `jupyter nbconvert --execute` (01: 4/4 клітинки з outputs, 02: 1/1, помилок нема).
