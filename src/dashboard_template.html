1. Порівняння моделей ⛶

PR-AUC кожної моделі на holdout-тесті. Пунктир — prevalence (рівень випадкового вгадування). У підписах — precision, recall та F2 на робочому порозі.

2. PR-криві ⛶

Залежність precision від recall. Тултіп показує значення всіх увімкнених моделей в одній точці. Клік по легенді — вмикання, подвійний клік — solo-режим.

3. Калібрування ⛶

Чи відповідає видана ймовірність реальній частоті тривог. Діагональ — ідеал. У легенді — Brier score (нижче — краще).

4. Важливість ознак ⛶

Топ-15 за gain з LightGBM. Фільтруй за типом: лаги, вікна, сусіди, час, текстові сигнали.

5. Прогноз у часі ⛶

Рожевий фон — години фактичної тривоги. Бірюзова область — ймовірність моделі. Жовтий пунктир — робочий поріг. Наведи курсор для деталей, тягни міні-слайдер для вибору періоду.

6. Розподіл ймовірностей ⛶

Гістограми ймовірностей для спокійних (синій) і тривожних (рожевий) годин обраної моделі. Жовта лінія — поточний поріг зі слайдера.

7. Confusion matrix ⛶

Теплова карта для обраної моделі. Рухай повзунок порогу — матриця, точність і rates перераховуються наживо.

0.15

8. Onset vs Continuation ⛶

PR-AUC окремо для початку тривоги зі спокою (onset, яскраве) і продовження (cont, тьмяне). Справжня цінність моделі — саме onset.

9. ROC-криві ⛶

Загальна роздільна здатність. Діагональ — випадкове вгадування. У легенді — ROC-AUC.

10. Brier score ⛶

Середньоквадратична похибка ймовірностей. Нижче — краще; 0.25 — рівень константного прогнозу при prevalence 0.5.
